# PixelGuess

Online, többjátékos pixel art rajzolós-kitalálós játék korai prototípusa.

## Helyi indítás

```bash
npm install
npm run dev
```

## Ellenőrzés

```bash
npm run lint
npm run build
```

Az első mérföldkő csak a React + TypeScript + Vite projektalapot és a helyi kezdőképernyőt tartalmazza. A Supabase szobák és a multiplayer következő lépések.
